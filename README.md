# YQArch Web CAD — المرحلة 3B: أوامر التعديل الهندسية (0.4.0)

تطبيق CAD يعمل في المتصفح، مبني بـ React وTypeScript وCanvas2D. تضم هذه النسخة **محرك المرحلة الثانية وواجهة تشغيل فعلية** فوق حزمة الأصول المحوّلة في المرحلة الأولى. وهي نواة رسم ثنائية الأبعاد وليست بديلاً متوافقاً بالكامل مع AutoCAD أو YQArch الأصلي.

## التشغيل

المتطلبات: Node.js 20+.

```bash
npm ci
npm run dev
```

افتح عنوان Vite المحلي الظاهر في الطرفية. لإنشاء نسخة إنتاجية:

```bash
npm run build
npm run preview:web
```

تحقق من المشروع:

```bash
npm test
npm run typecheck
```

واجهة التشغيل عربية، وتُفتح على رسم معماري تجريبي قابل للتعديل. استخدم **جديد** لبدء رسم فارغ، أو **فتح** لاستيراد ملف `.yqd` / JSON من الصيغة الأصلية. الحفظ يُنزّل ملف `.yqd`، ويوجد حفظ استرداد محلي تلقائي في المتصفح.

## ما اكتمل في المرحلة الثانية

- نموذج مستند CAD للخطوط، والنقاط، والدوائر، والأقواس، وPolyline مع bulge، والنصوص، والأبعاد، والتهشير، والكتل المدرجة.
- طبقات قابلة للإنشاء والتعيين والإظهار/الإخفاء والقفل، وألوان ACI، وأنواع الخطوط، والوحدات، ومقياس الرسم.
- عرض Canvas2D مع التحريك والتكبير بعجلة الفأرة، وملاءمة الرسم، وتحديد فردي وبنافذة/تقاطع.
- التقاط هندسي للطرف والمنتصف والتقاطع والعمودي والمركز والربع ونقطة الإدراج، إضافة إلى Ortho وPolar وGrid. مفاتيح سريعة: F3 وF7 وF8 وF10.
- سطر أوامر عربي تفاعلي يقبل أسماء الأوامر والاختصارات، وإكمال أوامر YQArch من ملف الأصول.
- التراجع والإعادة على مستوى الأمر، معاينة الأشكال أثناء الرسم، ومكتبة كتل بصورها المصغرة.
- حفظ وفتح الرسم بصيغة JSON الأصلية `yqweb-drawing@1` (`.yqd`)؛ أصول المرحلة الأولى تُنسخ إلى حزمة الإنتاج.

### الأوامر الأساسية

`LINE`, `PLINE`, `CIRCLE`, `ARC`, `RECTANG`, `POLYGON`, `ELLIPSE`, `TEXT`, `MTEXT`, `DIMLINEAR`, `DIMALIGNED`, `HATCH`, `INSERT`, `MOVE`, `COPY`, `ROTATE`, `SCALE`, `MIRROR`, `ERASE`, `UNDO`, `REDO`, `ZOOM`, `PAN`, `LAYER`, `OSNAP`, `GRID`, `DIST`, `LIST`.

أوامر التعديل الهندسي: `OFFSET`, `TRIM`, `EXTEND`, `FILLET`, `CHAMFER`, `ARRAY` (مستطيلة/قطبية), `STRETCH`, `BREAK`, `JOIN`.

اختصارات مختارة: `L` خط، `PL` Polyline، `C` دائرة، `A` قوس، `REC` مستطيل، `M` نقل، `CO` نسخ، `RO` تدوير، `E` مسح، `Z` تكبير/ملاءمة. الأوامر غير المنفذة من كتالوج YQArch تظهر كمخططة للمراحل التالية.

## البنية

```text
src/engine/   نموذج المستند والهندسة والعرض والالتقاط والاختيار والأوامر والحفظ
src/app/      واجهة React ومحمّل الأصول والرسم التجريبي
src/parsers/  محللات موارد المرحلة الأولى
assets/       الأصول المحوّلة: الخطوط، الأنماط، أنواع الخطوط، الصور المصغرة والكتل
```

صيغة الأصول موثقة في [`docs/asset-formats.md`](docs/asset-formats.md). أداة تحويل DWG المعزولة داخل `tools/dwg-convert/` ليست مطلوبة لتشغيل المحرر؛ ملفات JSON المحوّلة مرفقة مسبقاً.

## المرحلة 3A (الإصدار 0.3.0)

أوامر MOVE وCOPY وROTATE وSCALE وMIRROR (مع MIRRTEXT) وERASE وOOPS وEXPLODE تعمل على كل أنواع الكائنات، بما فيها البلوكات المدرجة والمعكوسة، مع تراجع كامل. أضيف التحديد بالنافذة والتقاطع والإضافة والإزالة والتحديد قبل الأمر وبعده، والمقابض مع التحرير بها (تمديد ← نقل ← تدوير ← تحجيم ← انعكاس). ويدعم موجه التحديد السياج `F` ومضلع النافذة `WP` ومضلع التقاطع `CP`. التفاصيل في `PHASE3A-STATUS.md`.

## المرحلة 3B

أوامر OFFSET (`O`) وTRIM (`TR`) وEXTEND (`EX`) وFILLET (`F`) وCHAMFER (`CHA`) وARRAY (`AR`) وSTRETCH (`S`) وBREAK (`BR`) وBREAKATPOINT وJOIN (`J`) بخيارات AutoCAD (Through/Erase/Layer/Multiple، النمطان Standard وQuick وFence/Crossing/Edge/eRase وShift للتبديل، Radius/Trim/Polyline، طريقتا الشطف، المصفوفة المستطيلة والقطبية…) مع أزرار في شريط الأدوات، ومكتبة هندسية جديدة (`curve.ts`, `offset.ts`, `corner.ts`, `modify.ts`). راجع `PHASE3B-STATUS.md` للتفاصيل والحدود وملاحظة المقارنة مع AutoCAD.

## نسخة سطح المكتب لـ Windows (exe)

التطبيق مغلف بـ Electron (`electron/main.cjs`) ويُبنى بـ electron-builder إلى:

- `YQArch CAD-<الإصدار>-x64-nsis.exe` — مثبّت (اختيار مجلد التثبيت، اختصار سطح المكتب وقائمة ابدأ، بالعربية والإنجليزية).
- `YQArch CAD-<الإصدار>-portable.exe` — نسخة محمولة تعمل بلا تثبيت.

البناء التلقائي على GitHub: الملف `.github/workflows/windows-exe.yml` يشغّل فحص الأنواع والاختبارات، ثم يبني ملفات exe على `windows-latest` مع كل دفع إلى `main` (تجدها في **Actions ← التشغيل ← Artifacts**). وعند دفع وسم إصدار مثل `v0.4.0` تُنشر الملفات تلقائياً في **Releases**:

```bash
git tag v0.4.0 && git push origin v0.4.0
```

البناء محلياً على Windows: `npm ci` ثم `npm run dist:win` (الناتج في `release/`). للتجربة السريعة: `npm run desktop`.
الملفات غير موقّعة رقمياً، لذلك قد يُظهر Windows SmartScreen تحذيراً عند أول تشغيل (اختر «مزيد من المعلومات ← تشغيل على أي حال»).

## حدود المرحلة

- لا يوجد استيراد/تصدير DXF أو DWG، ولا تعاون متعدد المستخدمين أو خادم؛ صيغة `.yqd` هي صيغة التخزين الأصلية الحالية.
- الأوامر الهندسية لها حدود موضحة في `PHASE3B-STATUS.md`؛ الأدوات المعمارية الذكية ما زالت ضمن المرحلة 4.
- بعض الخطوط الكبيرة تُحمّل عند الحاجة؛ جودة عرض النص تعتمد على الأصول المتاحة في الحزمة.

## ⚠️ الحقوق والترخيص

الكتل والأنماط والخطوط والصور المصغرة وإعدادات YQArch المرفقة مشتقة من موارد طرف ثالث. راجع قسم الترخيص في وثيقة المرحلة الأولى و`assets/report.md` قبل النشر أو إعادة التوزيع العام أو التجاري؛ لا يعني وجود الموارد هنا امتلاك حقوق إعادة نشرها. مكتبة التحويل في `tools/dwg-convert` تخضع لترخيص GPL-3.0، وهي معزولة عن كود التطبيق.
